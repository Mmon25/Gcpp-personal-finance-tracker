# Personal Finance Tracker (C++)

## Description
This is a simple C++ program that allows users to track income, expenses, and view their current balance.

## Features
- Menu-driven interface
- Add income
- Add expenses
- View current balance
- View transaction history

## Installation & Usage
1. Clone the repository
2. Compile the program: g++ main.cpp finance.cpp -o finance_tracker
3. Run the program: ./finance_tracker
4. Follow the on-screen menu
